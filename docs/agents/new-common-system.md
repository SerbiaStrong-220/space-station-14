# Создание обычной системы

Подходит, когда фича собирается из вызовов существующих систем, простой логики и компонентов с данными. Если нужна новая переиспользуемая основа для других систем, читай [new-fundament-architecture.md](new-fundament-architecture.md).

## Порядок
1. **Найди готовое.** Поищи по ключевым словам задачи в `Content.Shared`, `Content.Server` и папках `SS220`. Если система уже решает задачу, используй её и не пиши дубль.
2. **Выбери образец из списка ниже.** В репозитории много устаревших практик. Не копируй код только потому, что он лежит рядом: сверяйся с [csharp-style.md](csharp-style.md) и [ecs-performance.md](ecs-performance.md).
3. **Пиши:** компонент с данными и система с логикой. Общую часть размещай в `Content.Shared`, серверную и клиентскую вынеси в свои проекты.
4. **Нужна новая основа для других систем?** Остановись и переходи к базисному файлу.

## Правила хорошего тона

Не пиши тесты для системы. Если тебе нужны тесты для простой системы, то либо ты переусложнил логику, либо ты используешь не все доступные системы. Если ты всё ещё считаешь что тебе нужны тесты обратись к тексту под заголовком "Поддерживаемость кода" в [csharp-style.md](csharp-style.md)

## Современные системы-образцы
Список пополняется по мере появления новых паттернов.

### `EntityEffectSystem` (уже существует, используй, а не пиши заново)
Когда: нужно накладывать временные эффекты (урон, замедление и похожее), особенно если на одну сущность может действовать несколько модификаторов или у эффекта есть длительность.
Паттерн: эффект — отдельная сущность, она помещается в контейнер владельца. События, поднятые на владельце, ретранслируются на сущности-эффекты. Это решает конфликт нескольких источников одного и того же изменения на одном компоненте.
Готово из коробки: таймер действия, его обновление и продление.
Найди класс по имени и повтори его паттерн для своего эффекта.
