# Отложенные блокировки

В панели банов можно отложить любой поддерживаемый тип блокировки: серверный,
ролевой, чатовый или видовой. Условия выдачи: задержка в минутах либо следующий
переход к завершению раунда, началу раунда или лобби. Срок действия блокировки
отсчитывается с момента её активации.

Запись сохраняется в БД сразу, до подтверждения администратору. До активации она
не участвует в проверке входа и загрузке ограничений ролей/чатов. Существующий
механизм снятия блокировки позволяет отменить её до активации.

При штатном завершении сервер ожидает записи всей очереди в БД. При принудительном
завершении процесса или отключении питания исполнить код перед остановкой
невозможно: оставшиеся записи активируются при следующем запуске, до обработки
подключений. Повторная обработка не создаёт дубликаты.

При общей БД каждому серверу нужен **уникальный и постоянный `server.id`**.
Очередь принадлежит этому идентификатору; менять его между аварийной остановкой
и восстановлением нельзя без переноса `pending_server` в БД.

Миграции SQLite/PostgreSQL находятся в `Content.Server.Database/SS220/Migrations`.
Проверки:

```sh
dotnet test Content.Tests/Content.Tests.csproj -c Release --filter FullyQualifiedName~Content.Tests.SS220.PendingBans
```
