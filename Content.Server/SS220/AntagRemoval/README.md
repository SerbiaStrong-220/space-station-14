Добавление новой роли в removeantag

Руководство по добавлению поддержки снятия антагонистической роли через административную команду `removeantag`.

1. Изучение роли

Перед реализацией найдите прототип `MindRole` и проверьте:

- Как назначается роль: через `AntagSelectionSystem.MakeAntag()` или отдельную систему.
- Какие выдаются компоненты, предметы, способности, знания и цели.
- Есть ли штатная механика снятия роли.
- Какие эффекты могут появиться во время раунда.

2. Регистрация роли

Добавьте новую роль в:

1. `RemoveAntagRoles.cs` — ID `MindRole`.
2. `RemoveAntagSystem.Supported` — аргумент команды.
3. `RemoveAntagSystem.GetHandler` — обработчик.
4. `RemoveAntagSystem.RoleName` — локализованное название.
5. `RemoveAntagCommand.GetCompletion()` — автодополнение.
6. `Resources/Locale/ru-RU/ss220/removeantag.ftl` — локализацию.

3. Обработчик снятия

В папке `Handlers` создайте `EntitySystem`, реализующий `IAntagRemovalHandler`.

- `CanRemove` — проверяет возможность безопасного снятия без изменения состояния.
- `TryRemove` — удаляет специфические последствия роли.
- `RemovesMindRole` — `true`, если штатный обработчик самостоятельно удаляет `MindRole`.

Универсальная очистка целей, записанных предметов, опыта, фракций и уведомлений уже выполняется в `RemoveAntagSystem`.

4. Учёт назначения

Для ролей через `MakeAntag()` используются:

- `BeginGrant` — состояние до назначения.
- `EndGrant` — фиксация выданных эффектов.
- `CancelGrant` — завершение отслеживания при ошибке.

Если назначение проходит другим способом, добавьте отдельную интеграцию. Пример — `BeforeCultConversion` и `AfterCultConversion`.

Предметы учитывайте по конкретным `EntityUid`, а не по совпадению прототипа. Эффекты, выдаваемые позднее, отслеживайте отдельно.

5. Опыт и знания

В `RemoveAntagSystem.Experience.cs` добавьте сопоставление роли с `ExperienceAddSource`.

Для выдачи используйте существующие методы `GrantAntagBonuses`, `GrantAntagKnowledge` и `RegisterGrantExperience` по назначению.

**Источник опыта при выдаче и отзыве должен совпадать.** Иначе знания или очки могут остаться после снятия роли.

Сохраняйте знания профессии и бонусы других активных ролей.



**Не добавляйте роль в поддерживаемые, пока не реализовано безопасное удаление всех её специфических эффектов!!!!!!!!!!!!!!!!!!!**
